The admin panel is being migrated to Supabase with proper authorization. It will return once secure, role-based admin access is implemented.

What happened to admin?

The old admin panel relied on checking a specific email address in the browser — an insecure pattern that bypassed database security. This is being replaced with proper role-based access control through Supabase RLS policies and server-side authorization. The admin functionality will return in a later phase once the authorization framework is hardened.
